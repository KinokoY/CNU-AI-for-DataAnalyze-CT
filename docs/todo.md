■ 第 6 轮（下一步）：先拿可信基线，再调参
--------------------------------------------------------
0. **先看 fold 0 短跑权重的实测证据**（这直接决定先动哪个杠杆）：
   - 57/59 的 Dice = 0.0000，但预测体积是 GT 的 **5.0× / 36.1×** ⇒ **不是"漏检"，是没找对地方**；
   - 60 精确率 0.0203、预测 2.9× GT；仅肝脏 5 例命中 5/5、单例 FP 高达 260 514 mm³
     ⇒ **模型到处过预测**（峰值概率 0.9997 却零重叠 = 高置信度地预测了错误区域）；
   - `macro 0.1984` vs `池化 0.6747` ⇒ 现有分数**全部来自 case 33**（434 721 mm³），
     其余 3 例合计才 19 256 mm³；
   - 后处理阈值 50 mm³ 几乎无影响（+0.00016）—— 要处理的是 10⁴–10⁵ mm³ 的大块，不是小块。
   ⇒ **主要矛盾是过预测 + 定位失败，不是"召回不足"**。todo 原本列的三个召回侧杠杆
   （提 `pos_ratio_train`、Tversky 压 FP、逐样本 Dice）里，只有 **Tversky（α 压假阳性）** 与
   证据同向；先别急着提阳性比例。
1. **跑完整 5 折拿可信基线**（`for f in 0 1 2 3 4; do python -m src.train --fold $f; done`
   → `python -m src.evaluate --all`）。第 4 轮修掉两处 bug 后同一配置 best 从 0.0048 → 0.1983
   —— 旧的一切结论都作废，本轮之前先别谈调参；5 折报告要看的是**逐折 macro 的离散度**，
   单折（尤其 fold 0 的 case 33）不足以定论；
2. **按报告的分档与覆盖比例决定杠杆**（每次只改一个变量）：
   - 覆盖比例大量落在 `[0.00,0.10)` + 仅肝脏 FP 巨大 → 过预测：Tversky（α=0.7 压 FP）、
     调小 `eval.min_lesion_mm3` 之外的**后处理下界**暂不适用（要删的是大块）⇒ 更该动损失与容量；
   - `best_cover` 高但 Dice 低 → 位置对、范围大：考虑 `loss.batch=false`（逐样本 Dice）或
     提高 `eval.threshold`（0.5 → 0.6）看精确率/召回率的交换；
   - 覆盖比例在小病灶档全为 0 → 才是召回侧（`data.pos_ratio_train` 0.5 → 0.6、按病灶中心加权采样）；
   - 16 例训练病人 + 9.243 M 参数：容量/正则（`model.encoder_channels` 缩小、增强加强、
     早停 patience 调小）是与"过预测"同向的另一条线，但要单独一轮验证；
3. lr / 调度器 / 早停耐心：等 1、2 有对照曲线再动。

接回现有解码器微调 —— d2l 里"从零训练 vs 预训练微调"的对照。
  - 2.5D 三层输入**已在第 4 轮落地**，ImageNet 首层可原样用（不必压通道）；
  - resnet stem 先降 4 倍 ⇒ 整体下采样变 32 倍：`model.pad_to_multiple` 改 32、解码器改 5 级上采样；
  - 权重**只从本地路径读**（`model.pretrained_weights_path` 或 `~/.cache/torch/hub/checkpoints/`），代码绝不走网络；
  - 显存/耗时重新标定（编码器通道 64/128/256/512，bs=16 大概保不住），用 `--debug` 测；
  - 对照方式：独立 run 目录（如 `runs/fold0_imagenet`）+ 独立配置，报告里"基线 / 预训练"两栏并列。
**【禁忌】不要使用公开的肝脏/肝肿瘤分割权重**（LiTS、MSD Task03 等）：本数据集的编号（31–60）、
标签口径（1=肝脏、2=肿瘤且与肝脏互斥挖空）、48–52 几何错位被剔除，都与 LiTS 家族高度吻合、很可能同源
⇒ 用同类任务的公开权重等于把测试病人的标注喂进模型，5 折交叉验证直接失效。**只有 ImageNet 这类无关数据安全。**

跨轮约束（不可省）
--------------------------------------------------------
1. 划分按病人，不按切片；`data/splits.json` 入库、不做本地改动。
2. 5 例仅肝脏（32/34/38/41/47）只进训练集，用于约束假阳性；验证集分母恒为 4 例含肿瘤病人。
3. 重采样到 1mm 后**不对整图 resize**；尺寸差异只靠统一补边到 `data.target_hw`（512×512）处理，
   补边偏移 `pad_offset` 一路带到推理，裁回原始尺寸必须用它。
4. **病人级隔离**：划分按病人；采样器只在本折 train 的切片索引内重排/重复；2.5D 三层窗只在本病例内索引
   （越界用端点复制）。任何一条被破坏都会让 Dice 虚高 —— `src/selfcheck_data.py` 里有硬断言。
5. 每折划分、随机种子、指标口径写入产物，保证跨轮可复现；报告一律给 mean±std 与逐例值。
6. 代码只写、不本地执行；需要远程执行时先提交再给命令；产物路径一律相对仓库根。
7. **文档保持精简**：新增信息写进现有文档的对应位置，不要新开归档文件、不要复述代码。
