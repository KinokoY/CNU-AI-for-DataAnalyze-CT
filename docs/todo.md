■ 下一步：跑训练 → 看报告 → 再决定调参
--------------------------------------------------------
1. 单折试跑：`python -m src.train --fold 0`（约 12.5 s/epoch，200 epoch 上限 200 × 12.5 s ≈ 42 分钟，
   含每轮约 17 s 的整卷验证；早停 patience=20）。
2. 5 折：`for f in 0 1 2 3 4; do python -m src.train --fold $f; done`，再
   `python -m src.evaluate --all` 出 `reports/eval_summary.md`。
3. **按报告决定杠杆**（每次只改一个变量）。fold 0 短跑已经给出的方向性证据：
   - 57/59 的 Dice = 0.0000，但预测体积是 GT 的 5.0× / 36.1×、峰值概率 0.9997 ⇒ **不是漏检，是没找对地方**；
   - 60 精确率 0.0203、预测 2.9× GT；仅肝脏 5 例单例 FP 达 260 514 mm³ ⇒ **模型到处过预测**；
   - macro 0.1984 vs 池化 0.6747 ⇒ 现有分数几乎全部来自 case 33（434 721 mm³）；
   - 后处理阈值 50 mm³ 基本无效（逐例 Dice +0.00015）——要治的是 10⁴–10⁵ mm³ 的大块。
   ⇒ 主要矛盾是**过预测 + 定位失败**，不是"召回不足"。因此优先试与证据同向的杠杆：
   Tversky（α 压假阳性）、`eval.threshold` 0.5 → 0.6（看精确率/召回率交换）、
   容量/正则（16 例训练病人配 9.243 M 参数，`model.encoder_channels` 缩小或加强增强）；
   **先别急着提 `data.pos_ratio_train`**（那是召回侧杠杆）。
4. 单折不足以定论：5 折报告要看逐折 macro 的离散度与覆盖分档，别只盯均值。

■ 暂不做的（明确推迟）
--------------------------------------------------------
- 肝脏通道 / 三分类、期相分层报告、ImageNet 预训练对照 —— 都不在本版范围内。
- 迁移学习：ImageNet resnet18/34 当编码器接回现有解码器，对照"从零训练 vs 预训练微调"。
  要点：resnet stem 先降 4 倍 ⇒ `model.pad_to_multiple` 改 32、解码器 5 级上采样；
  权重只从本地路径读（代码绝不走网络）；显存/耗时用 `--debug` 重新标定；
  对照方式 = 独立 run 目录 + 独立配置，报告里两栏并列。
  **【禁忌】不要用公开的肝脏/肝肿瘤分割权重**（LiTS、MSD Task03 等）：本数据集编号（31–60）、
  标签口径（1=肝脏、2=肿瘤且与肝脏互斥挖空）、48–52 几何错位被剔除，都与 LiTS 家族高度吻合、
  很可能同源 ⇒ 用同类任务的公开权重等于把测试病人的标注喂进模型，5 折交叉验证直接失效。
  **只有 ImageNet 这类无关数据安全。**

--------------------------------------------------------
■ 跨轮约束（不可省）
--------------------------------------------------------
1. 划分按病人，不按切片；`data/splits.json` 入库、不做本地改动。
2. 5 例仅肝脏（32/34/38/41/47）只进训练集，用于约束假阳性；验证集分母恒为 4 例含肿瘤病人。
3. 重采样到 1mm 后**不对整图 resize**；尺寸差异只靠统一补边到 `data.target_hw`（512×512）处理，
   补边偏移 `pad_offset` 一路带到推理，裁回原始尺寸必须用它。
4. **病人级隔离**：划分按病人；采样器只在本折 train 的切片索引内重排/重复；2.5D 三层窗只在本病例内索引
   （越界用端点复制）。任何一条被破坏都会让 Dice 虚高 —— `src/selfcheck_data.py` 里有硬断言。
5. 每折划分、随机种子、指标口径写入产物，保证跨轮可复现；报告一律给 mean±std 与逐例值。
6. 代码只写、不本地执行；需要远程执行时先提交再给命令；产物路径一律相对仓库根。
7. **文档保持精简**：新增信息写进现有文档的对应位置，不要新开归档文件、不要复述代码。
