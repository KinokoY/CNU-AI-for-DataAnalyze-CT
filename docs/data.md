# CT 肝脏肿瘤分割 —— 数据事实（速查）

本文只留**编码必须依赖的实测事实**。数字来自远程 `scripts/probe_data.py` / `probe_labels.py` 的真实输出。
背景与工程约定见 `docs/README.md`，管线口径见 `docs/preprocess_notes.md`。

## 1. 组织与几何

- `data/` 平铺 30 对：`volume-<id>.nii` / `segmentation-<id>.nii`，`id` = 31…60 连续，约 4.33 GB。
- 原始维度 `512 × 512 × Z`（`Z` = 74–366）；**spacing 有 13 种**（面内 0.667–1.0、层厚 1.25–5.0）、
  **方位有 3 种** ⇒ 预处理统一到 `spacing=(1,1,1)` + RAS。
- 预处理后 nibabel 读回形状 `(nx, ny, nz)`、**切片轴在最后一维**；SimpleITK 读回是其转置，
  **两库不可混用**（`scripts/probe_axis.py` 是这条结论的实测来源）。

## 2. 标签语义（这条最要紧）

原始取值 `{0,1,2}`：**1 = 肝脏、2 = 肿瘤（肝内病灶）**，两者**严格互斥、零重叠**，
是**挖空式**标注 —— `label1 | label2` 才是完整肝脏。

- 推论：算**肝脏** Dice 要先合并两个 label；算**肿瘤** Dice 只用 label 2；三分类输出应为 3 通道。
- 5 例（32、34、38、41、47）只有 label 1 —— 无法判断是"确实无病灶"还是"漏标"，按**无病灶**处理。
- **缓存里的掩膜已二值化**（肝脏置 0、肿瘤置 1，只含 `{0,1}`）⇒ 取前景一律 `> 0`，**不要写 `==2`**。

## 3. 强度

- 标准 HU 口径；**地板值有三种**（−1024 / −2048 / −3024），是卷外 padding 的量化常量、
  占比 0.00–0.39，**不能当组织强度用**；全局范围 −3024…3247 ⇒ 固定 HU 窗必须先把地板夹掉。
- **case 之间增强期相不一致**（`body_p99` 258–808）⇒ 不做跨病例的固定窗归一化。
- 已落地口径：`preprocess.hu_clip=[-1000,1000]` 夹地板后线性映射到 [0,1]，
  量化存 `uint16`（`dataset` 里 `/65535` 还原；1 步长 ≈ 0.0305 HU）。

## 4. 质量问题：48–52 必须剔除

这 5 例的掩膜 affine 与影像不一致（平移差 293–652 mm），实测错位方式是**平面内 180° 旋转 + 明显平移**，
无法由 affine 自洽恢复 ⇒ **直接剔除**（不要试图用轴向翻转修复），划分里也不出现。

其余 25 例 shape/affine 一致、几何自洽；30 例体素 sha1 两两不同，**无重复病例**。

## 5. 划分与训练提示

- 可用 25 例 = **20 含肿瘤 + 5 仅肝脏**；5 折交叉验证（每折 4 例验证），按肿瘤体积分层，
  划分粒度是**病人**（`data/splits.json` 的 `split_level: "patient"`）。
- 样本量极小（20 例含肿瘤），模型容量/轮数都要保守；**肿瘤体积跨 3 个数量级**（652–434 721 mm³），
  预期**大病灶先学会、小病灶长期为 0** ⇒ 报告必须按病灶大小分层（口径见 `docs/preprocess_notes.md`）。
- 显存 40 GiB 而整卷 `512×512×366` ≈ 191 MB，整卷入 GPU 不可行 ⇒ 切片级训练，
  推理按 `pad_offset` 裁回原始面内尺寸。
